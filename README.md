# 😹 Funny Cat API Project

A simple and fun web project that displays a random funny cat image when the user clicks a button.

## 🚀 Features

- Get a random cat image
- New cat image on every button click
- Simple and clean UI
- Responsive image design
- Hover effects
- Uses a public Cat API

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- DOM
- CATAAS API

## 🌐 API Used

CATAAS - Cat as a Service

```text
https://cataas.com/cat
```

## 📌 How It Works

1. Click the **Get Funny Cat 😹** button.
2. JavaScript detects the button click.
3. A new cat image URL is created.
4. The cat image is displayed on the page.
5. Click again to see another funny cat.
